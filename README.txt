DNA ARMOUR WEBSITE

Open index.html to view the homepage.

Pages
- index.html: Homepage
- science.html: The Science
- shop.html: Buy or subscribe
- legal.html: Privacy, cookies, terms, delivery and returns

For local preview, run a static web server from this folder. For example:

  python3 -m http.server 4173

Then visit http://127.0.0.1:4173/

Before publishing
- Add the final product price, tax and delivery details.
- Connect the purchase controls to the chosen checkout provider.
- Add a monitored customer-service email address and telephone number.
- Replace the clearly marked sample reviews with verified customer reviews.
- Review the policy wording against the final business and fulfilment setup.

The website is self-contained and does not require an npm install or build step.
